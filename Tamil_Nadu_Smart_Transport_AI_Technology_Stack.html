Tamil Nadu Smart Transport AI

Comprehensive System Architecture, Technologies & Algorithms Specification

Production Ready All 38 TN Districts Machine Learning ML Engine Zero Server Standalone
Platform Overview: Tamil Nadu Smart Transport AI (TransitAI) is an intelligent, high-speed transportation planning and predictive fleet telematics platform tailored for the Tamil Nadu State Transport Corporation (TNSTC) and State Express Transport Corporation (SETC). It operates in dual deployment mode: a 100% browser standalone single-file architecture (`index.html`) or an optional Python Flask microservice backend.
1. Core Architecture & Deployment

Frontend Web Architecture

Technology:Vanilla ECMAScript 2023 (ES6+)
Markup:HTML5 Semantic Canvas & SVG
Styling:CSS3 Grid, Flexbox, Glassmorphism
Single-File Size:330 KB standalone (Zero npm dependencies)
Responsive:Mobile Bottom Navigation + Desktop HUD

Backend & Microservices

Runtime:Python 3.10+ (CPython)

ML Framework:Scikit-Learn 1.3.2

Model Storage:Joblib 1.5.3 (Serialized `.pkl`)

Accuracy:97.8% Delay Prediction Precision
